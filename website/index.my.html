Chatterbox သည် အသုံးပြုသူလမ်းညွှန်မရှိသော end-to-end ကုဒ်ဝှက်ထားသည့် မက်ဆင်ဂျာဖြစ်သည်။ မည်သူမျှ သင့်ကို ရှာဖွေ၍မရနိုင်ပါ၊ အကြောင်းမှာ ရှာဖွေရန် အညွှန်းမရှိသောကြောင့်ဖြစ်သည် — စကားပြောဆိုမှုတစ်ခုသို့ ဝင်ရောက်ရန် တစ်ခုတည်းသောလမ်းမှာ သင်ကိုယ်တိုင် တစ်စုံတစ်ဦးအား ပေးသည့်လင့်ခ်ဖြစ်သည်။

ဘာကွာသလဲ

မက်ဆင်ဂျာအများစု မလုပ်သည့် အချက်ခုနစ်ချက်

ဤအချက်တစ်ခုစီသည် နောက်ကွယ်တွင် စနစ်တစ်ခုရှိသော ဆုံးဖြတ်ချက်ဖြစ်ပြီး သင်ရှာရမည့် ဆက်တင်မဟုတ်ပါ။ တစ်စုံတစ်ရာ အလဲအလှယ်ဖြစ်သည့်အခါ ထိုအကြောင်း ဖော်ပြထားသည်။

  1. 01

    အသုံးပြုသူလမ်းညွှန် မရှိပါ

    အသုံးပြုသူအမည်ရှာဖွေမှု မရှိ၊ ဖုန်းနံပါတ်တွဲဆက်မှု မရှိ၊ “သင်သိနိုင်သောလူများ” မရှိပါ။ စကားပြောဆိုမှုတစ်ခုသို့ ဝင်ရောက်ရန် တစ်ခုတည်းသောလမ်းမှာ သင် channel ပြင်ပမှ တစ်စုံတစ်ဦးအား ပေးပို့သည့် ဖိတ်ကြားလင့်ခ်ဖြစ်သည်။ လင့်ခ်တစ်ခုစီသည် တစ်ကြိမ်သာ အလုပ်လုပ်ပြီး ၂၄ နာရီအကြာတွင် သက်တမ်းကုန်သည်၊ ထို့အပြင် မည်သူ မည်သူ့ကို ဖိတ်ကြားခဲ့သည်ဆိုသော အမြဲတမ်းမှတ်တမ်းကို ချန်ထားမည့်အစား စီစဉ်ထားသောလုပ်ငန်းစဉ်တစ်ခုက သက်တမ်းကုန်သွားသည့်များကို ဖျက်ပစ်သည်။

    ဤအရာသည် ကိုယ်ရေးကိုယ်တာဆက်တင်မဟုတ်ပါ။ ထွက်ခွာရန် လမ်းညွှန်ကိုယ်တိုင် မရှိပါ။

  2. 02

    သိမ်းဆည်းရန် အီးမေးလ်လိပ်စာ မရှိပါ

    အကောင့်ဖွင့်ခြင်းသည် သင့်အကြောင့် မည်သည့်အရာမျှ မမေးပါ။ သင့်အကောင့်သည် သင့်စက်ပေါ်တွင် ဖန်တီးထားသော စကားလုံး ၂၄ လုံးပါ ပြန်လည်ရယူရေးစကားစုဖြစ်ပြီး၊ ဆာဗာစစ်ဆေးသည့် credential ကို ထိုစကားလုံးများမှ ဆင်းသက်ထုတ်ယူသည် — ၎င်းသိမ်းဆည်းသည်မှာ မေးလ်လက်ခံနိုင်သည့် domain မဟုတ်သော domain အောက်ရှိ ကျပန်း label တစ်ခုသာဖြစ်သည်။ သင့်ပရိုဖိုင်မှတ်တမ်းတွင် အီးမေးလ်လိပ်စာ၊ ပြသမည့်အမည် သို့မဟုတ် ဓာတ်ပုံ URL မပါဝင်သဖြင့် အခြားသူတစ်ဦးဖတ်ရန် ပရိုဖိုင်လည်း မရှိပါ။

  3. 03

    စာများထက် ပိုမိုသော အရာများ ပိတ်ထားသည်

    စာ၏စာသားသည် လွယ်သောအပိုင်းဖြစ်သည်။ လင့်ခ်အစမ်းကြည့်ရှုမှုများနှင့် တိုက်ရိုက်တည်နေရာကိုလည်း တူညီသည့်နည်းလမ်းဖြင့် စကားပြောဆိုမှုသို့ ကုဒ်ဝှက်သည် — တည်နေရာမျှဝေမှုသည် ကိုအော်ဒီနိတ်များ၏ စီးဆင်းမှုဖြစ်ပြီး အခြားအရာအားလုံးလိုပင် ၎င်းကို အခြားစက်၏ကီးဖြင့် ပိတ်ထားသည်။ ပူးတွဲဖိုင်များကို အပ်လုဒ်တင်မီ ကုဒ်ဝှက်ပြီးဖြစ်သဖြင့် ဆာဗာကိုင်ဆောင်ထားသည်မှာ ၎င်းမဖွင့်နိုင်သော bytes များဖြစ်သည်။

  4. 04

    စာတိုင်းတွင် သီးခြားကီးရှိသည်

    one-to-one နှင့် group စကားပြောဆိုမှုအများစုသည် ratchet ကို အသုံးပြုသဖြင့် စက်တစ်လုံးထိပါးခံရခြင်းသည် ထိုမတိုင်မီရောက်ရှိခဲ့သည့်စာများကို ဖော်ထုတ်မည်မဟုတ်ပါ။ တစ်စုံတစ်ဦး၏ client မှ ပိုသစ်သော key material ကို မထုတ်ပြန်ရသေးသည့် စကားပြောဆိုမှုများသည် ထိုဂုဏ်သတ္တိမရှိသော long-lived key တစ်ခုတည်းသို့ ပြန်လည်ရောက်သွားသည်။

    စာတစ်စောင်၏အောက်ရှိ label က ၎င်းအမှန်တကယ်ရရှိသည့်အမျိုးအစားကို ပြောပြသည်။ ၎င်းသည် အက်ပ်အကြောင်း ဆိုဆောင်ချက်မဟုတ်ဘဲ ထိုစာအကြောင်း ဆိုဆောင်ချက်ဖြစ်သည်။

  5. 05

    မည်သည့် AI မျှ သင့်စကားပြောဆိုမှုများကို မဖတ်ပါ

    အနှစ်ချုပ်သူ မရှိ၊ ဘာသာပြန် မရှိ၊ စာသားပြောင်းခြင်း မရှိပါ။ ဤအက်ပ်တွင် မည်သည့်အရာမျှ စကားပြောဆိုမှုကို decrypt ပြုလုပ်ပြီး စီမံဆောင်ရွက်ရန် တတိယအဖွဲ့အစည်းထံ မပေးပို့ပါ၊ အကြောင်းမှာ ဤနေရာတွင် မည်သည့်အင်္ဂါရပ်မျှ ထိုသို့မလုပ်သောကြောင့်ဖြစ်သည်။ အကြံပြုပြန်စာများကို နောက်ဆုံးစာအနည်းငယ်မှ သင့်စက်ပေါ်တွင်သာ တွက်ချက်ပြီး မည်သည့်နေရာသို့မျှ မသွားပါ။

    ထိုအင်္ဂါရပ်များသည် code အတွင်းရှိပြီး ဤဗားရှင်းအတွက် ပိတ်ထားသည်; ၎င်းတို့ ပြန်လာရန် ရည်ရွယ်ထားသည်။ ကိုယ်ရေးကိုယ်တာမူဝါဒ၏ အပိုင်း ၆ သည် ၎င်းတို့ရောက်ရှိမည့် ဝန်ဆောင်မှုသုံးခုကို အမည်ဖြင့် ဖော်ပြထားပြီး ယနေ့ ၎င်းတို့ထံ မည်သည့်အရာမျှ မရောက်ရှိကြောင်း ဆိုသည်။ ၎င်းတို့ပြန်လာသောအခါ ထိုဖော်ပြချက်နှင့်အတူ ပထမဆုံးအသုံးပြုမီ အတည်ပြုချက်နှင့်အတူ ပြန်လာမည်။

  6. 06

    တစ်စုံတစ်ရာရှာဖွေခြင်းသည် သင့်မျက်ကွယ်တွင် မဖြစ်ပါ

    စာတစ်စောင်ရှိ အမည်တစ်ခုကို တို့လိုက်ပါ၊ Chatterbox သည် ၎င်း၏ Wikipedia ဆောင်းပါးကို ပြသမည်။ ထိုတောင်းဆိုမှုသည် တို့ချိန်တွင် ဖြစ်ပေါ်ပြီး အခြားနည်းဖြင့် မဟုတ်ပါ၊ ထို့အပြင် ၎င်းအကြောင့် မည်သည့်အရာမျှ စကားပြောဆိုမှုအတွင်း မရေးထားပါ။

    ယခင်ဗားရှင်းတစ်ခုသည် သင်ဖွင့်လိုက်သည့် စကားဝိုင်းတိုင်း၏ နောက်ဆုံးစာ တစ်ဆယ့်ငါးစောင်ကို စကင်ဖတ်ပြီး ဖွင့်တိုင်း Wikipedia ကို သုံးဆယ်ကြိမ်အထိ တောင်းဆိုခဲ့သည် — တစ်ချိန်တည်းတွင် မည်သည့်အရာမျှ မပြသဘဲ၊ အကြောင်းမှာ ကာများသည် တစ်ခါမျှ မဖွင့်ခဲ့သော အလံတစ်ခုနောက်တွင် ရှိနေခဲ့သောကြောင့်ဖြစ်သည်။ ၎င်းကို ပြုပြင်မည့်အစား ဖယ်ရှားလိုက်သည်။

  7. 07

    ကိုယ်ရေးကိုယ်တာမူဝါဒသည် မိမိမလုပ်နိုင်သည်များကို ဖော်ပြသည်

    ကုဒ်ဝှက်ခြင်းကို တစ်ခါမျှ လွတ်လပ်စွာ စစ်ဆေးမှုမပြုလုပ်ခဲ့ကြောင်း၊ ကျွန်ုပ်တို့ Google ၏ဆာဗာများကို ငှားရမ်းသောကြောင့် ၎င်းသည် ချိတ်ဆက်မှုတိုင်း၏ metadata ကို မြင်နိုင်ကြောင်း၊ ထို့အပြင် သင့်ပထမဆုံးစာမတိုင်မီ အစားထိုးခဲ့သော ကီးတစ်ခုသည် လုံးဝပုံမှန်အတိုင်း ပေါ်လိမ့်မည်ဖြစ်ကြောင်း ၎င်းဖော်ပြထားသည်။ အက်ပ်တွင်လည်း ဤဆိုက်တွင်လည်း တူညီသောစာသားဖြစ်ပြီး ဘာသာစကား ၅၃ မျိုးဖြင့် — ပိုမိုပျော့သော ဘာသာပြန်နှင့်တွဲသည့် အင်္ဂလိပ်မူရင်း မဟုတ်ပါ။

    အထက်ပါအရာများအနက် တစ်စုံတစ်ရာကို ယုံကြည်မည်ဟု ဆုံးဖြတ်မီ ဖတ်ပါ။

အမှန်တကယ် ဘာလုပ်သလဲ

ဤနေရာတွင် ဖော်ပြထားသည့် အရာအားလုံးတွင် သင်ရောက်ရှိနိုင်သော interface ရှိသည်။ ဤစာမျက်နှာရှိ မည်သည့်အရာမျှ code အတွင်းတွင်သာ ရှိသည့် စွမ်းရည်ကို မဖော်ပြပါ။

စာပေးစာယူ

စာသား၊ ဓာတ်ပုံ၊ ဗီဒီယို၊ ဖိုင်များနှင့် အသံမှတ်စုများ။ ပြန်စာ၊ ထပ်ဆင့်ပို့ခြင်း၊ တုံ့ပြန်ချက်များ၊ ဖတ်ပြီးအကြောင်းကြားချက်၊ ပင်ထိုးထားသောစာများ၊ မှတ်သားချက်များနှင့် အချိန်ဇယားဆွဲထားသောစာများ။

ခေါ်ဆိုမှုများသည် ဖြစ်နိုင်လျှင် WebRTC မှတစ်ဆင့် ကိရိယာနှစ်ခုကြားတွင် တိုက်ရိုက်ချိတ်ဆက်ပြီး၊ ရွေးချယ်စရာအဖြစ်မဟုတ်ဘဲ ပုံသေအားဖြင့် အသံနှင့်ဗီဒီယိုကို ကုဒ်ဝှက်ထားသည်။ ချိတ်ဆက်၍မရသောအခါ — များသောအားဖြင့် မတူညီသောကွန်ရက်များကြောင့် — ကုဒ်ဝှက်ထားသောလွှဲပြောင်းကိရိယာသည် ခေါ်ဆိုမှုကို ကုဒ်ဖြေ၍မရဘဲ သယ်ဆောင်ပေးသည်။

အကြံပြုပြန်စာများ

စကားပြောဆိုမှု၏ နောက်ဆုံးစာများမှ ရယူထားသော အကြံပြုပြန်စာအနည်းငယ်။ ၎င်းတို့ကို သင့်ဘာသာစကားရှိ စကားစုစာရင်းနှင့် သင့်စက်ပေါ်တွင်သာ တိုက်ဆိုင်စစ်ဆေးသည် — ၎င်းတို့ဖန်တီးရန် မည်သည့်နေရာသို့မျှ မည်သည့်အရာမျှ ပေးပို့ခြင်းမရှိပါ။

Wikipedia ရှာဖွေမှု

စာတစ်စောင်ကို ဖိထားပါ၊ ၎င်းအတွင်းရှိ အမည်တစ်ခုကို ရွေးပါ၊ ပြီးလျှင် စကားဝိုင်းမှ ထွက်ခွာစရာမလိုဘဲ ဆောင်းပါးကို ဖတ်ပါ။ တောင်းဆိုမှုတစ်ခု၊ သင့်တို့ချက်ဖြင့်၊ သင့်ကိုယ်ပိုင်ဘာသာစကားဖြင့်။

သင့်ကီး၊ သင့်ပြန်လည်ရယူရေးစကားစု

သင့်စာများကို decrypt ပြုလုပ်သည့် private key သည် သင့်စက်မှ တစ်ခါမျှ ထွက်မသွားပါ။ ၎င်းကို ပြန်လည်ရယူရေးစကားစုအနေဖြင့် ရေးမှတ်ထားနိုင်သည်; ကျွန်ုပ်တို့ ၎င်းကိုမကိုင်ဆောင်ပါ၊ သင့်အတွက် ပြန်လည်ရယူပေးလည်း မရနိုင်ပါ။

  • သင်ပူးတွဲသည့် ဓာတ်ပုံ၊ ဗီဒီယို၊ အသံနှင့် ဖိုင်များ
  • လင့်ခ်အစမ်းကြည့်ရှုမှုများနှင့် တိုက်ရိုက်တည်နေရာ
  • အသံမှစာသားပြောင်းချက်များ၊ သင့်ထံပြန်ရောက်လာသည်နှင့်
  • ခေါ်ဆိုမှု၏ အသံနှင့် ဗီဒီယို၊ စက်နှစ်လုံးအကြား

  • စကားပြောဆိုမှုတစ်ခုရှိကြောင်းနှင့် ၎င်းအတွင်း မည်သည့်အကောင့်များပါဝင်သည်
  • အကောင့်တစ်ခုစီ နောက်ဆုံးအသုံးပြုခဲ့သည့်အချိန်
  • ချိတ်ဆက်မှုတိုင်း၏ metadata၊ သင့် IP လိပ်စာအပါအဝင်
  • ခေါ်ဆိုမှုတစ်ခုပြုလုပ်ခဲ့ကြောင်း၊ မည်သူ့ကိုနှင့် မည်သည့်အချိန် — ၎င်း၏အသံ သို့မဟုတ် ဗီဒီယိုမဟုတ်
  • ခေါ်ဆိုမှုတစ်ခုကို ချိတ်ဆက်ရန် ပို့ဆောင်ရန်လိုအပ်သောအခါ နှစ်ဦးစလုံး၏ IP လိပ်စာများ — ၎င်း၏အသံ သို့မဟုတ် ဗီဒီယိုမဟုတ်ပါ
  • သင်ပေးပို့သည့် ပူးတွဲဖိုင်တိုင်း၏ ဖိုင်အမည်၊ အမျိုးအစားနှင့် အရွယ်အစား
